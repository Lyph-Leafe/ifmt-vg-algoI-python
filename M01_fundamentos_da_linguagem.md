# Módulo 01 — Fundamentos da linguagem

**Nível:** Básico  
**Carga horária sugerida:** 12–16 h  
**Pré-requisitos:** Nenhum.

## Objetivo de aprendizagem

Ao concluir este módulo, o estudante deverá aplicar os conceitos em um programa funcional, explicar as decisões tomadas e demonstrar os resultados com exemplos próprios.

## Conteúdos / aulas

- **Aula 01.** Instalar Python, configurar VS Code, terminal e executar scripts
- **Aula 02.** Variáveis, atribuição, tipos (`int`, `float`, `str`, `bool`, `None`) e conversão
- **Aula 03.** Operadores aritméticos, relacionais e lógicos; precedência
- **Aula 04.** Entrada e saída, `print`, `input` e f-strings
- **Aula 05.** Condicionais `if`, `elif`, `else`
- **Aula 06.** Repetição `for`, `while`, `range`, `break`, `continue`
- **Aula 07.** Erros de sintaxe, execução e uso inicial do depurador

## Exercícios práticos

- Construir um conversor de unidades com menu
- Implementar verificador de números primos
- Criar um jogo de adivinhação com limite de tentativas

## Projeto do módulo

Calculadora de terminal com menu, validação de entradas e operações reutilizáveis.

**Entregáveis:** código-fonte organizado, arquivo `README.md` com instruções de execução e demonstração das funcionalidades. A partir do módulo 07, incluir testes automatizados.

## Critérios para avançar

- [ ] Executa scripts de forma autônoma
- [ ] Resolve problemas com decisões e laços
- [ ] Consegue depurar erros básicos

## Autoavaliação

1. Consigo explicar, sem consultar a solução, o papel de cada componente usado?
2. Consigo alterar um requisito pequeno sem reescrever o sistema inteiro?
3. Consigo reproduzir o resultado em um ambiente limpo?
