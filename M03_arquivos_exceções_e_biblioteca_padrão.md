# Módulo 03 — Arquivos, exceções e biblioteca padrão

**Nível:** Básico sólido  
**Carga horária sugerida:** 12–16 h  
**Pré-requisitos:** Módulos 01–02.

## Objetivo de aprendizagem

Ao concluir este módulo, o estudante deverá aplicar os conceitos em um programa funcional, explicar as decisões tomadas e demonstrar os resultados com exemplos próprios.

## Conteúdos / aulas

- **Aula 01.** Leitura e escrita de arquivos com `pathlib` e `open`
- **Aula 02.** Context manager `with` para arquivos
- **Aula 03.** CSV e JSON com a biblioteca padrão
- **Aula 04.** Tratamento de exceções: `try`, `except`, `else`, `finally`, `raise`
- **Aula 05.** Exceções específicas e validação de dados
- **Aula 06.** Bibliotecas `datetime`, `collections`, `itertools`, `statistics`
- **Aula 07.** Noções de encoding, caminhos e portabilidade

## Exercícios práticos

- Persistir o gerenciador de contatos em JSON
- Importar e exportar um cadastro CSV
- Tratar arquivo inexistente e dados inválidos sem esconder exceções

## Projeto do módulo

Sistema de cadastro persistido em JSON, com backup e recuperação de erros de entrada.

**Entregáveis:** código-fonte organizado, arquivo `README.md` com instruções de execução e demonstração das funcionalidades. A partir do módulo 07, incluir testes automatizados.
