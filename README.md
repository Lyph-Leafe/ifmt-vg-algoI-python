# Algoritmos I com Python

Material da disciplina de **Algoritmos I** do IFMT Campus Várzea Grande (ensino médio técnico em Informática), do zero até antes de orientação a objetos.

Cada aula tem uma **apostila** (teoria + exercícios), o **código** mostrado no vídeo e uma **videoaula** gravada no Cursor. Cada módulo termina com um **desafio** que você implementa sozinho.

## Módulos

| Módulo | Conteúdo | Desafio |
|---|---|---|
| [01 · Fundamentos](aulas/M01_fundamentos/README.md) | instalação, variáveis, operadores, entrada e saída, `if`, laços, erros e depurador | [Calculadora de terminal](aulas/M01_fundamentos/desafio/apostila.md) |
| [02 · Coleções, funções e módulos](aulas/M02_colecoes_funcoes_modulos/README.md) | listas, tuplas, conjuntos, dicionários, comprehensions, funções, argumentos, módulos e docstrings | [Gerenciador de contatos](aulas/M02_colecoes_funcoes_modulos/desafio/apostila.md) |
| [03 · Arquivos, exceções e biblioteca padrão](aulas/M03_arquivos_excecoes_biblioteca/README.md) | arquivos com `pathlib` e `with`, CSV e JSON, `try/except`, validação, `datetime`, encoding e caminhos | [Cadastro em JSON com backup](aulas/M03_arquivos_excecoes_biblioteca/desafio/apostila.md) |

A lista completa de aulas está em [aulas/README.md](aulas/README.md). O plano de cada módulo (objetivos, exercícios e critérios para avançar) está nos arquivos `M01_...md`, `M02_...md` e `M03_...md` aqui na raiz.

## Como estudar

1. Baixe o material: botão verde **Code › Download ZIP** (ou `git clone`).
2. Abra a pasta no Cursor ou no VS Code.
3. Para cada aula: assista ao vídeo, leia a `apostila.md` e rode os programas da pasta `codigo/` no terminal, por exemplo:

       cd aulas/M01_fundamentos/aula02_variaveis_e_tipos/codigo
       python idade.py

4. Faça os exercícios do fim da apostila **com o seu código**, mudando os exemplos.
5. No fim do módulo, faça o desafio.

## Desafios: como entregar

Os desafios ficam no **seu próprio repositório no GitHub**. O passo a passo está em [modelo-aluno/COMO-ENTREGAR.md](modelo-aluno/COMO-ENTREGAR.md): você copia a pasta [`modelo-aluno`](modelo-aluno/) para um repositório seu e manda o link no Moodle.

## Regras de convivência com o código

- Pode (e deve) pedir ajuda para **entender** um erro.
- Não copie a solução pronta de ninguém, nem de IA: o objetivo é **você** treinar.
- Só avance de módulo quando conseguir explicar e modificar o código que escreveu.
