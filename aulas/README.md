# Aulas — Formação Python (Básico: Módulos 01 a 03)

Cada aula tem `apostila.md` (teoria + exercícios) e `codigo/` (os programas mostrados no vídeo).
Cada módulo termina com um **Desafio** (`desafio/apostila.md`): o projeto do módulo, que o aluno implementa sozinho. A entrega é no repositório de cada aluno ([como entregar](../modelo-aluno/COMO-ENTREGAR.md)).
Os vídeos são gravados no Cursor pela fábrica em `D:\SINGULARIDADE\aulas-python-tec` (pasta do roteiro entre parênteses).
